# 减肥搭子 · 公开演示版

这是「减肥搭子」的静态、公开展示版本，用于体验本地 7 天计划、手动饮食/运动记录、休息日、奖励与周复盘交互。

## 演示边界

- 固定为 DEMO 模式，不读取开发版或其他站点的存档。
- 数据与所选照片只保存在当前浏览器，没有账号、云同步或远端数据库。
- 不提供 AI 餐食识别，不会把照片或记录发送到服务器或第三方，也不会产生 AI 费用。
- 营养区间只根据用户手动填写并确认的食材、克数与本地静态参照估算；不构成医疗或减重建议。
- 宠物体态不会根据饮食、热量、体重、任务结果或奖励自动变化。
- 九态 WebP 为当前展示素材；未批准的候选步态素材未发布、未启用。

## 本地预览

在本目录启动任意静态文件服务器，例如：

```bash
python3 -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/`。
